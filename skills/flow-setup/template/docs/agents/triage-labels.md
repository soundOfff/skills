# Triage labels

Skills speak in five triage roles. This table maps each role to the label this repository's tracker uses. Edit the middle column to match labels that already exist.

| Role | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `{{label:needs-triage}}` | A maintainer needs to evaluate this issue. |
| `needs-info` | `{{label:needs-info}}` | Waiting on the reporter for more information. |
| `ready-for-agent` | `{{label:ready-for-agent}}` | Fully specified and ready for an agent to build unattended. |
| `ready-for-human` | `{{label:ready-for-human}}` | Needs a person to implement it. |
| `wontfix` | `{{label:wontfix}}` | Will not be actioned. |

When a skill names a role, apply the label from the middle column. Triage labels sit alongside any other labels the repository uses, so an issue can carry one of each kind. Create a missing label only when the approved publication plan includes it.
